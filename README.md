# CS3-OOP-template

## GameCharacter class

A basic GameCharacter with name and health points.  The class has methods that could show the health of the game character
using the format:

- **character** has **nn** health points

another method of the GameCharacter class is to set the health points.  The health points should always be of increments of 10. The method will give an appropriate error message if the health points is not an increments of 10.

**attributes:**
- +name:str
- -health:int

**methods:**
- +get_health()
- +set_health()
